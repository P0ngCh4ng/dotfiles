---
description: Switch default model/effort to Opus 4.8 + medium
allowed-tools: Bash(jq:*), Bash(mv:*), Bash(cat:*)
---

Set the persistent model and effort defaults in `~/.claude/settings.json` to **Opus 4.8 / medium**, the same way the built-in `/model` and `/effort` commands do.

Run:

```bash
jq '.model = "opus" | .effortLevel = "medium"' ~/.claude/settings.json > /tmp/claude-settings.json.tmp \
  && mv /tmp/claude-settings.json.tmp ~/.claude/settings.json
```

Then confirm to the user in one line: "Set model to Opus 4.8, effort to medium (saved as default for new sessions)".
