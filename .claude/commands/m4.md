---
description: Switch default model/effort to Fable 5 + high (most capable, most thorough)
allowed-tools: Bash(jq:*), Bash(mv:*), Bash(cat:*)
---

Set the persistent model and effort defaults in `~/.claude/settings.json` to **Fable 5 / high**, the same way the built-in `/model` and `/effort` commands do.

Run:

```bash
jq '.model = "fable" | .effortLevel = "high"' ~/.claude/settings.json > /tmp/claude-settings.json.tmp \
  && mv /tmp/claude-settings.json.tmp ~/.claude/settings.json
```

Then confirm to the user in one line: "Set model to Fable 5, effort to high (saved as default for new sessions)".
