---
description: Switch default model/effort to Haiku 4.5 + low (fastest, lightest)
allowed-tools: Bash(jq:*), Bash(mv:*), Bash(cat:*)
---

Set the persistent model and effort defaults in `~/.claude/settings.json` to **Haiku 4.5 / low**, the same way the built-in `/model` and `/effort` commands do.

Run:

```bash
jq '.model = "haiku" | .effortLevel = "low"' ~/.claude/settings.json > /tmp/claude-settings.json.tmp \
  && mv /tmp/claude-settings.json.tmp ~/.claude/settings.json
```

Then confirm to the user in one line: "Set model to Haiku 4.5, effort to low (saved as default for new sessions)".
